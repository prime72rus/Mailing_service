Необходимо реализовать CRUD для всех вышеописанных моделей (кроме логов (достаточно просмотра списка)).

Получение сообщений, клиентов пользователя, при создании рассылки.
В контроллере создания
```
def get_form_kwargs(self):
        kwargs = super().get_form_kwargs()
        kwargs.update({'request': self.request})
        return kwargs
```
В инициализаторе формы

```
def __init__(self, *args, **kwargs):
        self.request = kwargs.pop('request')
        user = self.request.user
        super().__init__(*args, **kwargs)
        self.fields['clients'].queryset = Client.objects.filter(owner=user)
        self.fields['mail'].queryset = Mail.objects.filter(owner=user)
```

## Рассылка

Автоматически можно присваивать рассылке стандартный статус.
- Если если время сейчас < времени начала, то "Создана";
- Если если времени начала < время сейчас < времени окончания, то "Активна";
- Если если время сейчас > времени окончания, то "Завершена".


### Первая задача

Смена статуса

Каждые n минут проверяем статус. При необходимости - меняем.


### Следующие задачи (рассылка)

3 периодические задачи, в зависимости от периода

1) Отправка сообщений активным рассылкам, раз в день; 
2) Отправка сообщений активным рассылкам, раз в неделю;
3) Отправка сообщений активным рассылкам, раз в месяц.

### Обработка отправки сообщений
Блок отправки сообщений можно поместить в try ... except ...
Результат ошибки можно записывать в логи (поле 'Ответ сервера' )

## Права

### Права менеджера
- **может** просматривать любые рассылки 
- **может** просматривать список пользователей сервиса (шаблон, контроллер с списком пользователей)
- **может** блокировать пользователей сервиса (кнопка 'заблокировать', 'активировать'. Смена поля is_active)
- **может** отключать рассылки (Для модератора добавить кнопку 'активации'/'деактивации' рассылки. Такой же
функционал можно добавить владельцу рассылки)
- **может** просматривать логи (возможно добавление данного функционала владельцу рассылки (просмотр логов его рассылок))
- **не может** редактировать (удалять) рассылки
- **не может** редактировать (удалять) сообщения, клиентов пользователей

### Права пользователя
- **может** просматривать только свои рассылки, сообщения, клиентов
- **не может** просматривать, редактировать, удалять рассылки других пользователей
- **не может** просматривать список пользователей
