# Сервис управления рассылками

## 📌 Описание проекта

Сервис позволяет пользователям создавать рассылки, управлять клиентами и сообщениями, а также отправлять письма вручную или по расписанию. В проекте реализованы роли пользователей, логирование попыток рассылки и кеширование с использованием Redis.

---

## 🚀 Функциональность

### Основная часть (обязательная по ТЗ):

* ✅ CRUD для клиентов (email, ФИО, комментарий)
* ✅ CRUD для сообщений (тема, тело письма)
* ✅ CRUD для рассылок (время начала/окончания, периодичность, статус, связь с сообщениями и клиентами)
* ✅ Отправка рассылок вручную через кнопку
* ✅ Логирование попыток отправки (успешно/не успешно, ответ сервера)
* ✅ Главная страница со статистикой (всего рассылок, активных, уникальных клиентов)

### Дополнительная часть (расширение функциональности):

* ✅ Регистрация и аутентификация пользователей (через email)
* ✅ Вход/выход, подтверждение email через письмо
* ✅ Сброс и восстановление пароля
* ✅ Ограничение доступа: пользователь видит только свои данные, менеджер — все
* ✅ Роли: менеджеры и обычные пользователи
* ✅ Отправка созданных и уже активных рассылок через кастомную команду management `send_mailings`

## 📂 Установка

Перед установкой создать БД PostgresQL (pgAdmin 4)

1. Клонировать репозиторий:

```bash
git clone https://github.com/prime72rus/Mailing_service.git
cd Mailing_service
```

2. Создать и активировать виртуальное окружение, установить зависимости:

Должен быть установлен `poetry`

```bash
poetry install
```

4. Настроить `.env` файл:


5. Применить миграции:

```bash
python manage.py migrate
```

6. Создать суперпользователя:

```bash
python manage.py createadmin
```

7. Запустить Redis-сервер и затем запустить проект:

```bash
redis-server
python manage.py runserver
```

## 📨 Отправка всех рассылок со статусом "Создана" или "Запущена"

Запуск в ручную из командной строки:

```bash
python manage.py send_mailings
```
